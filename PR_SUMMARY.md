- **GitHub Actions Workflow** (`.github/workflows/snake.yml`):
  - Automatically generates contribution snake animation
  - Runs daily at midnight UTC
  - Runs on every push to main branch
  - Can be triggered manually
  - Saves output to `output` branch

- **Dynamic Content** (Auto-updating):

## 🔧 Setup Required

For the snake animation to work:
1. Go to repository Settings → Actions → General
2. Under "Workflow permissions", select "Read and write permissions"
3. Save changes
4. Manually trigger the workflow from Actions tab (first time only)
